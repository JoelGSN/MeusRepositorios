## Métodos de Array

| Recurso | Ideia principal | Exemplo de aplicação |
| --- | --- | --- |
| `forEach` | Executar uma ação para cada elemento | Listar produtos no console |
| `map` | Transformar cada elemento e gerar um novo array | Gerar nomes ou produtos com desconto |
| `filter` | Selecionar vários elementos que atendem a uma condição | Produtos com estoque |
| `find` | Encontrar um elemento | Buscar produto por `id` |
| `findIndex` | Encontrar a posição de um elemento | Localizar um produto para atualização no array |
| `some` | Verificar se pelo menos um elemento atende à condição | Existe algum produto sem estoque? |
| `every` | Verificar se todos os elementos atendem à condição | Todos os produtos possuem preço válido? |
| `reduce` | Acumular valores ou calcular um resultado | Calcular o valor total do estoque |
